## Arquitectura propuesta antes del código

THE SHELL REPRESENTS NAVIGATION STATE. IT DOES NOT OWN NAVIGATION STATE. View proviene de App; investigación se lee mediante V03-008. En Activos, enlace global conserva URL canónica actual; en Asset360 usa return validado; desde otras áreas abre inventario por helper de intención. No cache de última investigación ni history propia. Collapse, drawer, tema y densidad son disposición/interacción/preferencias, nunca scope/filtros.

Primaria: Overview / Activos / Lifecycle & Investment / Calidad de datos (según cobertura existente). Agrupación visual no añade rutas. Secundaria/local: secciones de Asset360, controles/filtros de cada superficie. Contextual: relación de CI, QR/label, investigación y return. Breadcrumb expresa jerarquía real; retorno expresa investigación, no lista de clicks. Mantener breadcrumb de Asset360/V03-008 sin duplicarlo en header. No implementar global search ni command palette: no capacidad global demostrada.

Dirección elegida: hybrid sidebar/rail con etiquetas visibles incluso reducido, no jeroglíficos ni dependencia de tooltip. Top utility bar identifica página y modo; no hero. Light/Dark usan roles existentes, precisión geométrica y espacio Innergex; ningún color corporativo nuevo, marketing imagery o font externa. Nav current se distingue de selección de entidad, hover y focus. Desktop no anima ancho de grid (evita reflow repetido); drawer usa CSS panel200 y reduced0. Sin transiciones de página que bloqueen interacción.

Marca B se refina dentro del mismo concepto N conectado: terminales reducidas y separadas de diagonal, stroke compensado a16; geometría regular a24/32/64. C no se reabre; A sólo fallback si existe fallo objetivo. Candidato en shell/Storybook reversible para revisión; NO definitivo sin checkpoint humano, NO favicon/manifest hasta aprobación.

## Implementación y tradeoffs

- Desktop ≥1024: sidebar224 px; collapse104 px con nombres visibles y aria-current. Frente a256 heredado se recuperan32 px expandido y152 px reducido. Preferencia persistida sólo en igx-nexus:navigation-collapsed; tema/densidad mantienen keys existentes. No URL en storage, no remembered investigation.
- Tablet768–1023: rail104 px persistente, nombres envueltos; collapse no afecta ese layout. Mobile<768: drawer224 px o ancho disponible, header dos filas, modo con explicación visible, utilities44×44 y título multiline. Resize cierra drawer al entrar a tablet y devuelve foco a main cuando el trigger ya no es visible.
- AppShell agrega prop de disposición aditiva, dialog/aria-modal sólo al abrir, filtra targets ocultos del trap y usa token border-width-strong existente donde el CSS heredado nombraba thick inexistente. Se mantienen inert, Escape, restore y body-scroll cleanup. Skip link mueve foco sin reescribir hash de investigación; regresión cubierta con teclado.
- Primary current mantiene marcador3px + peso/texto/aria-current, focus exterior independiente, hover neutral y pressed interior. No nav destinations disabled; no fuentes ocultas renombradas como nuevas capacidades.
- Tabla/Graph no entran al sidebar como módulos separados. Shell consume canonicalHash/assetReturnHash/buildInvestigationLink; contrato, router, Explorer, Dashboard, Asset360 y Graph no modificados.
- Main permanece flexible sin nuevo max-width global; layout local sigue en cada superficie. Shell no introduce wrappers/card soup ni rediseña contenido.
- Rechazados top-nav-only (resta continuidad en superficies densas), icon-only rail (dependencia de memoria/tooltips) y sidebar256 permanente (coste espacial sin más destinos). Se acepta que nombres extensos ocupen2–3 líneas en rail; futura IA debe volver a medirlo antes de agregar destinos.
- Marca B refinada es candidato reversible en shell, ApplicationMark y exports SVG en assets/branding/proposals/v03-003. Evaluación técnica:16 preserva N y evita terminales voluminosas; reconocimiento/preferencia estética requiere decisión humana. No evidencia de fallo objetivo que justifique A; C permanece histórico. No favicon/manifest ni fuentes externas.
- Motion: sólo drawer200ms y feedback existente; reduced0ms verificado. Collapse sin animación de ancho para evitar reflow por frame; cambio de contexto no demora interacción. Sin biblioteca nueva.
