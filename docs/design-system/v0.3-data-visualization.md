# V03-002 — Foundation de visualización de datos

Se preservan 52 definiciones data-viz del baseline: categorical 6, sequential 5, diverging negativo/neutro/positivo, estados y ejes/grid/tooltip por tema. No se instala chart engine ni se construye dashboard. El color categórico identifica clase, nunca severidad implícita. Tipografía de ejes y leyendas: 14 px cuando es información esencial; números tabulares y unidades visibles.

| Rol | Uso / contrato | Alternativa sin color |
|---|---|---|
| Categorical | Máximo seis clases legibles; orden estable por dominio | Labels directos, símbolos y leyenda |
| Sequential | Magnitud ordenada con unidad y rango declarado | Valores, bandas etiquetadas, tabla accesible |
| Diverging | Desviación sobre punto medio real | Signo/valor/línea de referencia; no falso cero |
| Severity | Sólo condición suministrada; aliases del eje severity nuevo | Icono, texto y forma |
| Coverage | n/N y scope neutral; datos parciales se anotan | Counts y etiqueta “parcial”, sin rojo por porcentaje |
| Observed / inferred | Línea sólida / discontinua, label y procedencia | Texto y tabla de relaciones; inferido no parece hecho confirmado |
| Unknown / unavailable | Gap explícito, label de motivo | Nunca barra cero ni promedio que oculte falta de datos |

Gridlines sutiles no llevan significado por sí solas; ejes usan text.secondary, tooltip elevated con border.control. Legend, interacción/focus y límites usan contraste comprobable. Si un color de serie no distingue el dato frente a fondo, añadir trazo/borde/label y verificar contraste no textual del elemento necesario; no declarar toda la paleta accesible por tener buenos textos.

Zero state: sólo “0” si medición válida; Empty: no entidades para filtro; Unavailable: fuente no accesible; Partial: fecha/scope/n/N y cálculo limitado; Loading: actividad real, no valores inventados. Tabla alternativa debe conservar datos y provenance. Tooltip accesible con teclado y cierre; información esencial no exclusivamente hover. Gráficos complejos requieren validación específica en el ticket consumidor.

Prohibidos rainbow arbitrario, gauges decorativos, 3D, color sin significado y fake realtime. No animar entradas como prueba de actualización; indicar timestamp recibido. Reduced motion preserva cambios por labels/estado, elimina desplazamientos; forced colors debe conservar patrones/labels y system colors. No tomar observado de Demo como evidencia Live.

Los patrones de Carbon (roles) y React Aria (interacción desacoplada) se aplican sin incorporar paquetes nuevos; referencias/licencias/tradeoffs en `v0.3-foundations.md`. Referencias de observabilidad de V03-001 inspiran densidad/inspección; su interfaz no se copia.
