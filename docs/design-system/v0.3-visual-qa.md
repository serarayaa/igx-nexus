Conservar viewport, tema, densidad, estado y SHA para hacer las capturas repetibles.

## Gates y límites

Tokens: build determinista, parity, aliases; contrastes texto 4.5:1 y elementos necesarios 3:1 según uso; pruebas de counts inválidos/unknown sin inventar cero; keyboard selection y focus independiente; dark/light y density; existing Storybook/web tests; build/typecheck; npm audit gate alto; git diff check. [WCAG 2.2](https://www.w3.org/TR/WCAG22/) aporta criterios, no una certificación automática del producto.

La revisión humana exigida por §33 del archivo de solicitud cubre lockup, mark, paleta, tipografía, estados, componentes y combinaciones de tema/densidad. Propuestas de marca aisladas. Decisión final sólo puede habilitar siguiente fase con condiciones explícitas; no aprobar estética por tests.
