# V03-002 — Componentes, composites y migración

React Aria Components y Lucide se preservan. Variantes, temas y densidad se resuelven por tokens/CSS compartidos. No construir una biblioteca universal por anticipación. Componente ausente no equivale a defecto: incorporar wrapper sólo ante consumidor validado.

| Componente solicitado | Baseline / interacción | Decisión y aceptación |
|---|---|---|
| Button / IconButton | React Aria, variants primary/secondary, sizes, focus/disabled | KEEP + POLISH pressed; icon-only exige aria-label; touch target adecuado |
| Input / Search | Labels, description y error asociados | KEEP; themes/density; largos y error visible |
| Select | Select nativo local web; sin wrapper público | KEEP local; wrapper futuro con label y teclado |
| Checkbox | Nativo dentro DataTable | KEEP; selección etiquetada, no selección por hover |
| Radio / Toggle | Sin familia pública | ADD sólo con necesidad; nativo/React Aria, no div clickable |
| Badge / Status | Badge y StatusBadge públicos, taxonomía por tono | KEEP compatibility; ADD evidence/coverage/severity explícitos |
| Tooltip | Sin primitive público estable | ADD con consumidor; no información esencial oculta |
| Popover / Dropdown/Menu | Sin familia pública estable | ADD futuro con dismiss, focus, navegación y contraste |
| Tabs | Composición local Asset 360 | KEEP; revisar teclado/ARIA en ticket de superficie, no asumir accesible por nombre |
| Breadcrumb | Composición de enlaces locales | EVOLVE cuando shell lo requiera; nav label y current |
| Table | Native table, headers/sort/caption, selection checkbox, overflow contenido | KEEP + POLISH selección; pruebas keyboard y counts |
| Pagination | Público, buttons y página actual | KEEP; límites/disabled y labels |
| Drawer / Dialog | Sidebar AppShell con inert/Escape/focus; paneles locales | KEEP shell; no afirmar dialog genérico existente; wrapper futuro valida trap/return |
| Empty / Error / Loading | FeedbackState público, Spinner | KEEP; error no falso empty, retry explícito, reduced motion |
| Skeleton | Sin familia pública | ADD sólo cuando evita layout shift; no fake data |
| Toast / notification | Alert existente; no toast genérico | KEEP Alert; no cola/timers nuevos sin necesidad |

El test automático de primitives no certifica composiciones locales. Storybook se convierte en contrato visual **de componentes compartidos**, junto con código/tests/ADR; las pantallas necesitan pruebas propias. Drift: web añade headings/contadores y badges locales; la migración futura sustituirá sólo casos cuyo significado coincida y conservará información operativa.

## Contratos conceptuales de composites

| Patrón | Anatomía / comportamiento | No uso |
|---|---|---|
| workspace header | Título, scope, modo Demo/Live, fuente/fecha, acción primaria | Hero o KPI soup |
| section header | H2 + explicación breve + acción relevante | Card para cada subtítulo |
| filter bar | Labels, filtros activos/remover, reset, resultado, disclosure móvil | Reducir controles a iconos sin nombre |
| scope selector | Scope explícito; cambio confirma efecto en resultados | Selección de entidad implícita |
| entity header | Identidad exacta, tipo, provenance, freshness, acción | Estado resumido sin razón |
| evidence summary / provenance | Estado + fuente/fecha/método + scope/cobertura | Confundir inferido con observado |
| status summary | Condición suministrada + motivo + evidencia faltante separada | Derivar critical desde porcentaje |
| investigation CTA | Ver evidencia/abrir entidad, conserva filtros/retorno | Acción que promete inteligencia no disponible |
| context panel | Identidad y contexto, cierre, scroll, foco devuelto | Panel modal por CSS sin semántica |

V03-002 implementa primitives semánticos y muestra composición de revisión; no publica API de Technology Workspace ni cambia navegación.

## Responsive y migración

Desktop: resultados y contexto pueden coexistir; Tablet: priorizar resultados y disclosure de contexto; Mobile/320 px: identidad y acciones esenciales primero, filtros expandibles, columnas prioritarias/alternativa de lista cuando proceda. Native table puede tener scroll horizontal **dentro** de su región etiquetada; el documento no debe desbordar. No encoger textos ni esconder evidencia para ganar densidad. Entity header envuelve identificador largo; controles del graph requieren nombres, targets y alternativa tabular. No se rediseñan graph/nav aquí.

Secuencia: foundation aditiva → semántica → core → composites revisados → consumidor por superficie. Shell tiene su ticket; Workspace valida estado compartido/URL/performance; Asset 360 mantiene cuatro secciones; Overview atiende “qué requiere atención y por qué”; especializadas usan disclosure. Cada migración tiene screenshot before/after, regresiones y rollback; sólo eliminar legacy después de demostrar consumidores migrados. No big-bang.

No nuevas dependencias visuales ni motion. Una corrección mínima del lockfile `source-map-js` 1.2.1→1.2.2 atiende el advisory alto que rompe el gate de npm audit en el baseline; no altera capacidades ni añade paquete. Backend/contratos/providers quedan fuera de alcance. V02-023 sigue separado.
