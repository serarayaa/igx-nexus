# Registros de Decisiones

Los **Architecture Decision Records (ADR) canónicos de IGX NEXUS viven en `docs/architecture/`**.

Este directorio se conserva únicamente como referencia histórica para evitar enlaces rotos o confusión durante la evolución inicial del repositorio. No deben crearse aquí duplicados de decisiones ya registradas como ADR.

Índice actual:

- `docs/architecture/adr-0001-product-boundaries.md`
- `docs/architecture/adr-0002-asset-ci-taxonomy.md`
- `docs/architecture/adr-0003-ui-design-system.md`

Las futuras decisiones técnicas relevantes —autenticación, integración con GLPI, reconciliación de datos, identidad QR, persistencia/caché y topología de despliegue— deben incorporarse siguiendo la numeración de `docs/architecture/`.
